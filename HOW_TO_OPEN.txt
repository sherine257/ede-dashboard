How to open the EDE dashboard

IMPORTANT: Do not open GitHub Raw links. They show code text and the dashboard will not run.

Best option:
1. Download DT_Projects_Dashboard_SharePoint.zip
2. Unzip it
3. Right-click DT_Projects_Dashboard_SharePoint.html
4. Open with Google Chrome

ZIP download:
https://github.com/sherine257/ede-dashboard/raw/cursor/contract-management-system-ac61/DT_Projects_Dashboard_SharePoint.zip

HTML download (use Save As if the browser shows text):
https://github.com/sherine257/ede-dashboard/raw/cursor/contract-management-system-ac61/DT_Projects_Dashboard_SharePoint.html
